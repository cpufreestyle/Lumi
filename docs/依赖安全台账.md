## 已修复：brace-expansion（2026-10-19）

**修复方式不是加 override，而是删掉一个错误的 override。** 上一轮给 `windows/package.json`
加的 `"brace-expansion": "^1.1.21"` blanket override 把 minimatch 的传递依赖也压坏了：

- `minimatch@3.1.5` 需要 `brace-expansion@^1.1.7`
- `minimatch@5.1.9` / `minimatch@9.0.9` 需要 `^2.0.x`
- `minimatch@10.2.6` 需要 `^5.0.8`

压到 1.1.21 后，`minimatch@10` 的解构导入 `brace_expansion_1.expand` 变成 undefined
（1.1.21 是 CJS `module.exports = expandTop`，无命名导出），报
`TypeError: (0 , brace_expansion_1.expand) is not a function`。

删除该 override 后依赖树自然收敛到正确版本：`minimatch@3 → 1.1.21`、
`minimatch@5/@9 → 2.1.7`、`minimatch@10 → 5.0.12`，本次推送关闭 3 条告警。
（brace-expansion 历史累计 9 条告警，其中 6 条在 2026-10-18 已关闭，
故本次净关闭 3 条；1.1.21 已是最新 1.x，CVE 已修。）
**教训：override 跨主版本压传递依赖前，必须 `npm ls <pkg>` 核对。**

## 环境备注

- npm registry 指向 `registry.npmmirror.com`，其 audit 端点未实现（`npm audit` 本地不可用），
  GitHub 侧 Dependabot 是唯一信号源。tarball 安装不受影响。
- 本机到 `api.github.com` 的 HTTPS 链路不稳定（SOCKS 代理抖动，`git push` 走 SSH 正常）。
  拉取告警若超时，给 `gh` 显式走代理再试：`HTTPS_PROXY=socks5h://127.0.0.1:1082 gh api ...`
- 根 `package-lock.json` 与 `windows/package-lock.json` 均使用 lockfileVersion 3。
- **`~/.ssh/config` 里 github.com 走 `ProxyCommand nc -x 127.0.0.1:1082`，该 SOCKS 代理
  经常不在监听**，症状是 `git push` 报 `Connection closed by UNKNOWN port 65535`。
  本机到 ssh.github.com:443 与 github.com:22 均可直连，代理挂了不必修代理，
  用一次性配置绕过即可（不要改 `~/.ssh/config`，用户平时是要用代理的）：

  ```bash
  printf 'Host github.com\n    Hostname ssh.github.com\n    Port 443\n    User git\n    IdentityFile ~/.ssh/id_ed25519\n    IdentitiesOnly yes\n' > /tmp/ssh_noproxy
  chmod 600 /tmp/ssh_noproxy
  GIT_SSH_COMMAND="ssh -F /tmp/ssh_noproxy" git push origin main
  ```

  注意本机同时开放 8888 端口（另一个代理），与 1082 不是同一个，别混用。

## 维护纪律

每次推送后 GitHub 返回的漏洞计数若与本表「当前总数」不一致，以 GitHub 为准并更新本表。
核对命令（改计数就必跑，别靠记忆）：

```bash
gh api 'repos/cpufreestyle/Lumi/dependabot/alerts?per_page=100&state=open' \
  --jq 'group_by(.dependency.package.name)
         | map({pkg:.[0].dependency.package.name, n:length,
                sev:(map(.security_advisory.severity)|unique|join(",")),
                fix:(map(.security_vulnerability.first_patched_version.identifier // "—")|unique|join(","))})
         | sort_by(-.n) | .[] | "\(.n)\t\(.pkg)\t\(.sev)\tfix=\(.fix)"'
```

本台账不替代 CI 自动化；若启用 `.github/dependabot.yml`，应在 PR 模板里引用此文档
以避免重复 triage。
