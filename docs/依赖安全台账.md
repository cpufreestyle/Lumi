## 已修复：proxy-addr（2026-10-18）

原 22 条中唯一在根 `package.json` 生产依赖树的是 proxy-addr（`express` 传递依赖，
随 `npm start` 上线），严重度 critical，漏洞为 IPv4-mapped IPv6 信任子网绕过导致 IP 伪造。
已通过根 `package.json` 增加 override 修复：

```json
"overrides": { "proxy-addr": "^2.0.8" }
```

本地版本 2.0.7 → 2.0.8（补丁级，API 无变化）。`npm install` 报告 `changed 1 package`，
diff 仅涉及 package.json 与 package-lock.json；`npm test` 41 条全过，无回归。
Dependabot 告警 #86 应在推送后自动关闭。

剩余 21 条全部在 `windows/` 的 Electron 依赖树（本地开发与 Windows 打包才触及），
复评触发条件维持原判断：计划做 Windows 发版或 Electron 主版本升级时一并评估；
其中 vite 5→6、esbuild 0.21→0.25 需单独验证 `npm run build:win`，
不可与其它改动混在一次提交里。

## 维护纪律

每次推送后 GitHub 返回的漏洞计数若与本表「当前总数」不一致，以 GitHub 为准并更新本表。
核对命令（改计数就必跑，别靠记忆）：

```bash
gh api 'repos/cpufreestyle/Lumi/dependabot/alerts?per_page=100&state=open' \
  --jq 'group_by(.dependency.package.name)
         | map({pkg:.[0].dependency.package.name, n:length,
                sev:(map(.security_advisory.severity)|unique|join(",")),
                fix:(map(.security_vulnerability.first_patched_version.identifier // "—")|unique|join(","))})
         | sort_by(-.n) | .[] | "\(.n)\t\(.pkg)\t\(.sev)\tfix=\(.fix)"'
```

本台账不替代 CI 自动化；若启用 `.github/dependabot.yml`，应在 PR 模板里引用此文档
以避免重复 triage。
