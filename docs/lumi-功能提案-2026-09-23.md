## Tier 1 · 强创新

### 1. 划词 AI 快驾（剪贴板 → 本地 LLM）⭐⭐⭐ ✅ 已实现（2026-09-24）
> 落地：`Modules/AIAssist/AIAssistSettings.swift`（动作/端点规整/请求体/SSE 解析纯逻辑）、
> `AIAssistController.swift`（剪贴板监听走 PollingCoordinator + URLSession 流式）、
> `AIAssistViews.swift`（胶囊动作条 + 助手面板 + 设置）、AppState/IslandViews 挂载新模块；
> `Tests/LumiTests/AIAssistSettingsTests.swift`（12 用例）；`swift test` 83/83 通过。
- **一句话**：复制任意文本，胶囊浮出「翻译 / 总结 / 解释 / 改写」动作条，秒回结果。
- **依据**：定位与现有 `ClaudeCode` / `Codex` 模块（CLI 会话启动器）完全不同——本功能是
  「无会话、秒回」的轻量 AI；项目已有 `Core/Keychain.swift`（凭据安全存储）、`AppState` 的
  HUD 浮层模式（音量 HUD 现成范式）。
- **实现要点**：
  - 剪贴板监听用 `NSPasteboard.general.changeCount`（事件驱动，符合项目约定），默认关闭、需显式开启；
  - API 走 OpenAI 兼容端点（`baseURL` + `key` + `model` 可配，可指向本机自建代理），SSE 流式渲染；
  - 凭据入 Keychain，不落 UserDefaults；面板明示「数据仅发往你配置的端点」。
- **工作量**：约 500-700 行（新模块 `Modules/ClipAI`）。
- **风险**：剪贴板隐私感知 → 开关默认关 + 首次弹一次说明。

### 2. AI CLI 用量看板（Codex / Claude Code 成本可视化）⭐⭐⭐ ✅ 已实现（2026-09-24）
> 落地：`Modules/CLIUsage/CLIUsageModels.swift`（两种日志逐行解析 +  Codex 会话去重聚合
> + 公开价定价 + 格式化纯逻辑）、`CLIUsageController.swift`（增量字节扫描，偏移持久化，
> 按需轮询档位）、`CLIUsageViews.swift`（今日卡片 / 7 日柱图 / 模型明细）；
> `Tests/LumiTests/CLIUsageParserTests.swift`（14 用例，真实日志样本）；
> `swift test` 97/97 通过。
- **一句话**：解析本机 CLI 会话日志，在面板展示今日/本周 token 消耗、费用估算、会话趋势。
- **依据**：`CodexViews` / `ClaudeCodeViews` 目前只是启动器；作者本人即重度 CLI 用户；
  纯本地零网络；Codex 会话在 `~/.codex/sessions/*.jsonl`、Claude Code 在
  `~/.claude/projects/*.jsonl`，均含 `usage` 字段。
- **实现要点**：
  - JSONL 增量解析 + 按日期聚合；结果防抖落盘（复用 `scheduleLayoutPersist` 模式）；
  - 采集频率复用 `LiveDetection` 的「面板可见 2s / 不可见 30s」档位（`PollingCoordinator`）；
  - 费用按可配置单价估算（模型名可配）。
- **工作量**：约 400 行；无网络无隐私新增面。

### 3. 会议助手：入会倒计时 + 一键入会 ⭐⭐ ✅ 已实现（2026-09-23）
> 落地：`Modules/Calendar/MeetingLink.swift`（解析纯逻辑）、`MeetingReminderScheduler.swift`
> （会前 1 分钟本地通知 + 「加入会议」动作）、`CalendarViews.swift`（横幅 + 行内加入按钮）、
> `Tests/LumiTests/MeetingLinkParserTests.swift`（14 用例）；`swift test` 64/64 通过。
- **一句话**：检测到带会议链接的日历事件，胶囊显示「12min 后开会」，一键唤起 Zoom/Teams/腾讯会议。
- **依据**：`Calendar` 模块已有 EventKit；事件 notes/location/URL 中可解析
  `zoommtg://` / `msteams://` / `https://*.zoom.us/j/...`；与 HANDOFF「会议检测免打扰」互补（那个是免打扰，这个是入口）。
- **实现要点**：
  - 正则/URL 解析 meeting 链接 → 按钮按优先级调 `NSWorkspace.open`；
  - 会前 1 分钟 HUD 提醒（`UNUserNotificationCenter`）；
  - 唤起 Zoom 前按约定先用 `NSWorkspace.runningApplications` 查运行态。
- **工作量**：约 300 行，集中在 Calendar 模块。

## Tier 3 · 备选

### 12. 语音听写（调用本机 whisper.cpp）⭐⭐ ✅ 已实现（2026-09-26）
> 落地：`Modules/Dictation/Models/WhisperCLI.swift`（路径解析/模型发现/参数拼装/输出提取
> 纯逻辑，25 条单测）、`Controllers/DictationController.swift`（AVAudioRecorder 录 16kHz
> 单声道 WAV → Process 起 whisper-cli → 结果写剪贴板）、`Views/DictationBriefView.swift` +
> `Views/DictationExpandedView.swift`（录音按钮/结果区/模型下载指引/语言与翻译设置）、
> `Core/AppState.swift` 挂载 `.dictation`、`Core/IslandScreenGeometry.swift` 面板默认
> 360×520、`Resources/Info.plist` 补 `NSMicrophoneUsageDescription`；
> `Tests/LumiTests/WhisperCLITests.swift`；swift test 191/191 通过。详见
> `docs/whisper-dictation-integration.md`。
- **一句话**：点一下麦克风说话，停止后 whisper.cpp 本机转写，文本自动进剪贴板；可钉语言、可一键翻译成英语。
- **依据**：输入效率刚需（聊天/文档/代码注释口述）；whisper.cpp 模型 GGML 格式成熟、
  Metal 加速在 M 系芯片上 base 档即可近实时；音频不出本机，零隐私外传、零 API 费用。
- **实现要点**：
  - 录音直接出 16kHz 单声道 PCM WAV（whisper 原生输入格式），免 ffmpeg 中转；
  - `-np -nt` 下 stdout 仅含结果（日志走 stderr），仍对 stdout 做日志/时间戳防御过滤；
  - 模型完整性用「档位体积下限」判定，防下载到一半的模型进列表；
  - 语言 auto/zh/en/ja/ko + 内置 `-tr` 翻译开关， UserDefaults 持久化。
- **工作量**：约 700 行（新模块 + 测试 + 文档）。
- **风险**：首次需下载 ~148MB 模型 → 面板内置下载页/curl 命令复制；麦克风 TCC 需 Info.plist 声明。
